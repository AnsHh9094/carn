# Kunal — UX Designer & Video Editor Portfolio

> **Production Suite**: [https://kunall.de5.net](https://kunall.de5.net) · [Vercel Mirror](https://kunal-puce.vercel.app)

High-performance cinematic post-production and UX design portfolio for **Kunal** — MSc User Experience Design graduate (Edinburgh Napier University, 2025) and professional Video Editor (4+ years lead post-production experience across high-retention social campaigns, commercial visualizers, and event aftermovies).

---

## ⚡ Tech Stack

- **Framework**: React 18 + Vite 6 + TypeScript (Strict Mode)
- **Styling**: Tailwind CSS + Custom Typography Scale
- **3D & Visuals**: Three.js (`@react-three/fiber` & `@react-three/drei`) + WebGL Shaders
- **Motion & Smooth Scroll**: GSAP + Framer Motion + Lenis
- **Icons**: Lucide React
- **Deployment**: Vercel (Edge Network, SPA Routing, Global CDN)

---

## 🎬 Key Features

- **Monumental Typography Hero**: Depth-staged hero with interactive focus chips, mouse parallax, and real-time 3D particle canvas.
- **Cinematic 16:9 Video Carousel**: Active preview loops, custom WebGL image shaders, and responsive modal video playback.
- **Authentic Production Credentials**: Verified MSc User Experience Design timeline, professional certifications, and brand collaborations.
- **Performance Optimized**: Streamlined asset delivery with H.264 CRF 24 video compression and WebP image formats.
- **Accessible & Semantic**: WCAG-compliant color contrast, keyboard navigation, and zero layout shift.

## 🛠️ Local Development

```bash
# Clone the repository
git clone https://github.com/AnsHh9094/carn.git
cd carn

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
